# Инструкция: проект Oracle SQL Developer Data Modeler

Концепция системы описана в [README.md](README.md), объяснение каждой таблицы — в [MODEL.md](MODEL.md).

## Состав репозитория

| Файл | Что это |
|---|---|
| `nawigator.dmd` + `nawigator/` | Проект Data Modeler: реляционная модель `Nawigator`, её диаграмма и физическая модель под Oracle Database 21c. |
| `nawigator.sql` | DDL, сгенерированный Data Modeler из проекта: 30 таблиц, PK/UK/FK/CHECK, индексы, комментарии. |
| `Nawigator.png` | Диаграмма, экспортированная из Data Modeler (**Print Diagram → To Image File**). |
| `MODEL.md` | Зачем нужна каждая таблица и почему она устроена именно так. |
| `README.md` | Исходная концепция проекта, не менялась. |

`nawigator.dmd` и папка `nawigator/` — один проект: Data Modeler хранит его как файл-заголовок и папку с XML.
Копировать и коммитить их нужно только вместе.

## Открыть проект

В Oracle SQL Developer 24.3 (Data Modeler встроен):

1. **File → Data Modeler → Open…** и выбрать `nawigator.dmd`.
2. Если диаграмма не открылась сама: **View → Data Modeler → Browser**, затем `nawigator → Relational Models → Nawigator`, двойной щелчок.

В отдельном SQL Developer Data Modeler проект открывается через **File → Open**.

Диаграмма разложена по колонкам слева направо:

| Колонка | Таблицы |
|---|---|
| 1 | Справочники осей профиля: `CITIZENSHIP_GROUPS`, `COUNTRIES`, `RESIDENCE_BASES`, `RESIDENCE_PURPOSES`, `EMPLOYMENT_TYPES` |
| 2 | Профиль, правила, языки: `AVAILABILITY_RULES`, `USER_PROFILES`, `LANGUAGES`, `TRANSLATIONS` |
| 3 | Доступ и аудит: `PERMISSIONS`, `ROLE_PERMISSIONS`, `ROLES`, `USERS`, `CHANGE_LOG` |
| 4 | Работа клиента: `HELPER_ACCESS`, `HELPER_NOTES`, `USER_PROGRESS`, `USER_DOCUMENTS` |
| 5 | Сценарии и граф процедур: `LIFE_SITUATIONS`, `SITUATION_PROCEDURES`, `PROCEDURES`, `PROCEDURE_STEPS`, `PROCEDURE_DEPENDENCIES` |
| 6 | Учреждения и документы: `INSTITUTIONS`, `INSTITUTION_OFFICES`, `PROCEDURE_DOCUMENTS`, `DOCUMENTS`, `DOCUMENT_ISSUERS` |
| 7 | Источники и словарь: `OFFICIAL_SOURCES`, `GLOSSARY_TERMS` |

Картинка или PDF диаграммы: **File → Data Modeler → Print Diagram → To Image File / To PDF File**.

## Перегенерировать DDL после правок

**File → Data Modeler → Export → DDL File**, в списке выбрать **Oracle Database 21c**, затем **Generate → OK** и сохранить поверх `nawigator.sql`.

В физической модели (`Physical Models → Oracle Database 21c`) у всех колонок `ID` выставлен вариант автоинкремента
`IDENTITY_CLAUSE`. Поэтому ключи генерируются как `GENERATED BY DEFAULT AS IDENTITY`, без отдельных sequence и триггеров.
Новой автоинкрементной колонке нужно выставить там же тот же вариант.

## Развернуть схему в Oracle

Подходит Oracle 12.2 и новее: 19c, 21c, 23ai, Oracle Database Free.

Сначала под SYSTEM (или ADMIN в Autonomous) в нужной PDB создать владельца схемы:

```sql
CREATE USER nawigator IDENTIFIED BY "Change_me_1" QUOTA UNLIMITED ON users;
GRANT CREATE SESSION, CREATE TABLE, CREATE SEQUENCE TO nawigator;
```

Затем подключиться как `nawigator`, открыть `nawigator.sql` в SQL Developer и нажать **Run Script (F5)**. Или через SQLcl:

```
sql nawigator/Change_me_1@//localhost:1521/FREEPDB1 @nawigator.sql
```

Скрипт сначала создаёт все таблицы и только потом добавляет внешние ключи, поэтому порядок таблиц в нём не важен.
Чтобы пересоздать схему с нуля, выполнить `DROP USER nawigator CASCADE;` и повторить шаги выше.

## Соглашения об именах

Все имена английские, в верхнем регистре и не длиннее 30 символов.
Ограничения называются `PK_<ТАБЛИЦА>` и `UK_ / FK_ / CK_ / IDX_<сокращение>_<смысл>`. Сокращения таблиц:

| | | | | |
|---|---|---|---|---|
| `CTG` CITIZENSHIP_GROUPS | `CNT` COUNTRIES | `RSB` RESIDENCE_BASES | `RSP` RESIDENCE_PURPOSES | `EMT` EMPLOYMENT_TYPES |
| `AVR` AVAILABILITY_RULES | `UPR` USER_PROFILES | `LNG` LANGUAGES | `TRN` TRANSLATIONS | `PRM` PERMISSIONS |
| `RPM` ROLE_PERMISSIONS | `ROL` ROLES | `USR` USERS | `CHL` CHANGE_LOG | `HLA` HELPER_ACCESS |
| `HLN` HELPER_NOTES | `UPG` USER_PROGRESS | `UDC` USER_DOCUMENTS | `LSI` LIFE_SITUATIONS | `SPR` SITUATION_PROCEDURES |
| `PRC` PROCEDURES | `PST` PROCEDURE_STEPS | `PDP` PROCEDURE_DEPENDENCIES | `INS` INSTITUTIONS | `INO` INSTITUTION_OFFICES |
| `PDC` PROCEDURE_DOCUMENTS | `DOC` DOCUMENTS | `DIS` DOCUMENT_ISSUERS | `SRC` OFFICIAL_SOURCES | `GLT` GLOSSARY_TERMS |
